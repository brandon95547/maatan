# Maatan React + Tailwind Homepage

A responsive React homepage for Maatan, designed in a Modern Mystical Luxury, Gothic Mysticism, and Sacred Geometry visual style.

## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

## Production build

Run `npm run build`.

## Main files

- `app/page.tsx` — React homepage components and content
- `app/globals.css` — Tailwind import, theme fonts, sacred geometry, and atmospheric effects

The layout and responsive behavior use Tailwind CSS. Custom CSS is limited to the ornamental sacred geometry, Gothic arch, atmospheric background, and animations.
